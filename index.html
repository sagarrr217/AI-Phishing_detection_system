AI Phishing Detection System — Architecture & Build Steps

Complete engineering guide to build, train, and deploy this project

Step 1

Problem Definition & Architecture Design

Design a decoupled 3-tier system: (1) Reactive Web Frontend (HTML/CSS/JS) for instant user inspection, (2) Python FastAPI Backend for asynchronous model inference and WHOIS/DNS lookup, (3) Machine Learning Engine trained on 500k+ malicious & benign URLs.

Step 2

Gather Datasets (Phishing vs. Legitimate)

Collect high-quality labeled data from verified open-source threat feeds:

  • Phishing Feeds: PhishTank (phishtank.org CSV API), OpenPhish community feed, URLhaus (abuse.ch).
  • Legitimate Feeds: Tranco Top 1 Million domains list, Alexa Top Sites, Common Crawl benign URLs.

Step 3

URL Feature Extraction Pipeline

Transform raw URL strings into numerical feature vectors across 4 major dimensions:

  • Lexical: URL length, hostname length, path depth, token counts, digit-to-letter ratio.
  • Structural: Presence of IP address, '@' redirect symbol, '//' double slashes, hyphens in domain.
  • Homoglyphs & Spoofing: Typosquatting distance from top 500 brand names (Levenshtein distance & Punycode xn--).
  • Information Theory: Shannon Entropy of domain and path to detect Domain Generation Algorithms (DGA).

Step 4

Model Training & Evaluation

Train an ensemble model (Random Forest / XGBoost / LightGBM) for fast sub-50ms inference, or fine-tune a lightweight Transformer (DistilBERT) for character-level URL sequence embeddings. Measure Precision, Recall, and ROC-AUC (target >98% accuracy on zero-day URLs).

Step 5

Build Web API & Deploy User Interface

Expose a POST /api/v1/scan-url endpoint with FastAPI. Connect the front-end user experience with one-click verification, visual gauge meters, explainable AI flags, and defensive suggestions.

FastAPI Production Microservice (api.py) 
# api.py - FastAPI AI Phishing Verification Endpoint
from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, HttpUrl
import math, re, tldextract, joblib

app = FastAPI(title="PhishShield AI API", version="2.0")

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["*"],
    allow_headers=["*"],
)

class URLRequest(BaseModel):
    url: str

def calculate_shannon_entropy(text: str) -> float:
    if not text:
        return 0.0
    entropy = 0
    for x in set(text):
        p_x = float(text.count(x)) / len(text)
        entropy += - p_x * math.log(p_x, 2)
    return round(entropy, 3)

def extract_features(url: str):
    ext = tldextract.extract(url)
    domain = ext.domain + "." + ext.suffix
    subdomain = ext.subdomain
    is_ip = bool(re.search(r'^(?:[0-9]{1,3}\.){3}[0-9]{1,3}$', ext.domain))
    
    return {
        "url_length": len(url),
        "domain_length": len(domain),
        "has_ip": 1 if is_ip else 0,
        "subdomain_count": len(subdomain.split('.')) if subdomain else 0,
        "hyphen_count": domain.count('-'),
        "at_symbol": 1 if "@" in url else 0,
        "double_slash": 1 if "//" in url[8:] else 0,
        "is_https": 1 if url.startswith("https://") else 0,
        "entropy": calculate_shannon_entropy(domain)
    }

@app.post("/api/scan-url")
def scan_url(payload: URLRequest):
    features = extract_features(payload.url)
    # model = joblib.load("phishing_model.pkl")
    # threat_prob = model.predict_proba([list(features.values())])[0][1]
    return {
        "url": payload.url,
        "features": features,
        "status": "success"
    }
